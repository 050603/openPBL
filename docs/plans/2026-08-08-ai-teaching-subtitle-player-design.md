# AI 授课字幕播放器设计

## 目标

将学生 AI 授课阶段原有的高占用头像气泡区改为与课件同层的字幕控制区。当前字幕必须由正在播放的 TTS action 直接驱动，自动滚动到当前内容，并提供播放/暂停、前后翻页、上一句/下一句、静音、倍速和自动连播。

## 方案选择

采用“播放 action 驱动字幕”的方案。播放引擎在每条 speech action 开始时传出其 action index，字幕区以该索引作为唯一权威位置并平滑居中。上一句/下一句直接让播放引擎从目标 speech action 重新开始，因此字幕与声音同时切换。相比按字符估算进度，这一方案不会因音色、停顿或服务商差异产生字幕错位；相比修改课程生成结构，它也不会改变讲稿质量、课件内容或课程节奏。

宽屏使用右侧教学轨，利用 16:9 课件两侧的剩余空间，释放原底栏占用的垂直高度；窄屏响应式回到底部。课件、字幕与控制区共用连续背景，只保留一条结构分隔线，不再使用多层卡片和悬浮阴影制造嵌套播放器观感。

字幕默认只显示当前正在朗读的一句，前后字幕保留在同一滚动轨道中，仅在用户滚轮或触摸浏览时短暂显现，停止浏览后重新聚焦当前句。右侧教学轨同时容纳知识图谱小型预览，通过场景的 `knowledgePointIds` 高亮当前讲授节点；完整图谱通过弹窗展开。页面底部不再保留独立知识图谱区域。

## 质量边界

- 不修改课程生成提示词、场景拆分、讲稿、TTS 生成和教学时序。
- 新课程继续使用既有完整生成管线；播放器只读取已有 speech actions。
- 上一句/下一句基于已有 speech action 定位，无论使用预生成音频或浏览器原生 TTS，都会重新播放目标语句。
- 进入讨论、问答、学生输入或互动任务时，自动恢复原互动面板，保证课堂交互能力不因字幕 UI 被削弱。
- 旧课程允许缺少新的精确 cue 元数据；播放器按文本匹配首条可用字幕作为兼容回退。

## 验证

- 单元测试验证 action index 优先于文本匹配。
- 播放引擎回归测试验证 speech 回调扩展不改变原播放行为。
- TypeScript 与 ESLint 验证接口和组件接线。
- 视觉检查重点覆盖宽屏单行布局、窄屏双行布局、长字幕滚动以及互动面板切换。
