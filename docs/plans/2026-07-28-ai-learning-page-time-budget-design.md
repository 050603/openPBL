# AI 授知逐页时间预算设计

## 目标

把备课阶段分配给 AI 授知的时间逐级落实到每一个语义页面，并让课堂运行时真正执行同一份预算。页面总时间必须由自然语速 TTS 讲稿、学生阅读与思考、实践操作、反馈讲解和页面切换共同构成，不使用改变语音播放速度的方式凑时长。

## 方案选择

可选方案有三种：

1. 固定比例：按页面类型给讲稿和操作时间套固定比例。实现简单，但无法反映题型、步骤数和任务难度，正是现有误差的主要来源。
2. 全部交给大模型：由大模型同时决定页面结构、操作时间和讲稿量。表达灵活，但预算不可稳定复现，也难以审计。
3. 确定性预算 + 大模型受约束生成：系统根据页面类型、任务结构、难度和 TTS 实测语速计算预算，大模型只负责在预算内组织有效内容。

采用方案 3。时间计算保持确定性，大模型负责教学内容判断，两者职责清晰。

## 逐页预算模型

每页满足：

`页面总时间 = 自然语速讲稿时间 + 学生阅读思考时间 + 学生操作/答题时间 + 页面切换时间`

反馈与答案解析属于讲稿时间的一部分，不能重复计时。

- PPT/slide：主要时间用于讲解，仅保留约 3–6 秒的页面切换时间，不制造无意义空白。
- interactive：根据控件类型、步骤数、任务难度计算阅读理解与操作时间。代码、案例分析和多步骤模拟获得更高操作预算。
- quiz：根据题目数量、题型和难度计算读题、思考、作答时间；讲稿预算包含简短引导和答案解析。
- 所有页面都保留足够的最小讲解时间。如果任务复杂度超过页面预算，系统压缩或简化页面任务，而不是延长课程或提高 TTS 速度。

## TTS 内容量反推

系统先解析最终实际使用的 provider、model、voice，并加载对应的实测校准数据；没有实测数据时才使用该模型的保守种子参数。播放速度固定为 `1.0`。

从页面总时间扣除学生活动和切换时间后，得到讲稿目标秒数。再根据该模型/音色的中文字符每分钟、英文词每分钟和标点停顿特征，反推：

- 目标讲稿单位数
- 允许的最小/最大单位数
- 使用的校准来源和有效语速

生成提示必须明确这些边界，并要求通过增加或减少与当前知识点直接相关的概念、依据、例子、反例、步骤和反馈来匹配时间。禁止重复套话、引入图谱外知识或调整播放速度。

## 运行时执行与校验

互动/测验页在引导讲稿后插入可由学生提前完成的操作门；操作上限来自逐页预算，不再被 180 秒截断。每页最后插入固定的页面切换计时，PPT 页因此也会真实执行几秒翻页时间。

生成后按同一 TTS 模型和音色估算全部讲稿时长，并把“讲稿 + 学生活动 + 切换”与页面总预算比较。超出误差时只进行一次内容纠偏，再选择更接近总活动目标的版本。运行时继续记录实际 TTS 音频时长、页面停留和学生操作完成时间，供教师端偏差分析使用。
