# 基于学习证据的无感自适应课程设计

## 目标

主课程完整覆盖本节课大纲要求。个性化机制不再给学生贴层次标签，也不在课堂现场生成或弹窗播放“分支”，而是从备课期已经审核的额外资源池中，根据具体学习证据选择内容，并在同一个播放器中连续编排。

## 备课顺序

1. 确认课程基本信息、学习目标与知识图谱。
2. 生成并审核完整主课程大纲，确保所有必学内容都在主课中清晰讲授。
3. 生成最多 5 道先决知识前测题；必要时一题融合多个相关先决知识。
4. 为每个知识模块配置约 3 道测验题。
5. 基于完整主课逐页审查后，生成额外资源大纲：
   - `prerequisite`：主课未完整讲授、但理解新课必需的先决知识；
   - `worked-example`：不同于主课的新例题；
   - `application`：新应用或直观案例；
   - `extension`：迁移、边界、思考与开放挑战。
6. 教师确认每份资源的新增价值、潜在重叠页、插入证据、时长与生成指导。
7. 生成 PPT、讲稿、TTS、互动成品并逐份预览；资源未就绪时不能依赖课堂现场生成。

## 运行时决策

### 正式主课前

- 前测逐题映射到先决知识点。
- 只有答错且会影响本节新知识理解的知识点，才能匹配 `prerequisite` 资源。
- 没有缺口时直接进入主课程。

### 每个模块测验后

- 答错：显示题目解析，记录教师端个人与班级共性错误；不重复讲授同一内容。
- 达到掌握阈值且额外资源预算充足：选择一份已审核的新例题、应用或拓展资源。
- 未达到阈值或时间不足：继续主课程。

### 播放连续性

播放器始终占据同一页面区域。系统在主课程课堂和额外资源课堂之间切换数据源，不打开弹窗、不要求学生确认切换；资源播放完成后自动恢复主课程进度。

## 去重规则

每份资源必须包含：

- `noveltyStatement`：相对主课新增的学习价值；
- `mainCourseOverlapSceneIds`：可能重叠、生成时必须避开的主课页；
- `generationGuidance`：明确新案例、讲解顺序、互动方式和不得复述的内容。

缺少有效新增价值的资源不能触发，也不能被教师确认为可发布方案。

## 教师可观测性

教师端不显示学生层次，而显示：

- 前测分数与具体先决知识缺口；
- 当前主课进度和模块测验分数；
- 每份额外资源的证据、插入点、去重、成品、未使用和时间条件；
- 实际已学习的额外资源数量；
- 错题与班级共性问题。

教师仍可按学生关闭或重新开启个性化资源编排。

## 非功能要求

- 课堂运行时不调用课程生成接口。
- 决策应为本地确定性计算，正常情况下无额外等待。
- 使用稳定大纲 ID 绑定模块测验，运行时场景 ID 仅用于播放与诊断。
- 每份资源最多播放一次；所有决策保存审计快照。
- 主课和额外资源复用同一 PPT、TTS、互动和播放管线。
