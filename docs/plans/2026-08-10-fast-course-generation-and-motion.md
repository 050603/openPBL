# 快速课程生成与生成动效实施计划

> **For Codex:** Execute this plan in order and keep each stage independently verifiable.

## 目标

将备课流程升级为两种共用同一份课程数据的生成模式：默认的“快速生成”和可随时进入的“分步设计”。同时以成熟开源动效为基础，替换目前的摆锤和零散转圈动画，让所有长时 AI 任务都呈现清楚、精美、可理解的中文进度。

## 设计与架构原则

- 快速模式不是简化数据模型。它必须依次产生基础信息、知识图谱、项目成果、评价方案、六阶段架构、主课脚本、个性化路径和最终课堂。
- 两种模式写入相同的 `Course` / `CourseContent` 字段；教师可单向进入高级分步设计逐阶段查看和修改。
- 云端启用持久任务，页面关闭后继续运行；本机未启用后台能力时明确提示不要离开页面。
- 每一阶段完成后立即保存，并记录阶段、摘要、时间和质量检查结果，支持恢复和追溯。
- 自动生成包含结构校验和最终质量复核；结构性错误不得静默进入下一阶段。
- 动效统一沿用最终课程资源页已经验证的 React Bits Stack 卡片堆叠语言，并针对每个生成阶段重新设计卡片内容。

## 任务

### 1. 建立统一生成动效组件

- 新增可复用的阶段翻卡片动效，包含本次课程真实内容卡片、扫描光效和中文当前操作。
- 支持全屏任务、页面内流式任务和紧凑按钮三种密度。
- 支持 `prefers-reduced-motion`，并补充第三方许可说明。

### 2. 接入现有七阶段

- 替换 `AiGenerationOverlay` 摆锤。
- 主课脚本先显示统一弹窗，首条流式页面到达后关闭弹窗，由页面内逐页内容接管反馈。
- 替换主课脚本、详细大纲、个性化路径和各阶段按钮中的裸 `Loader2`。
- 进度文案全部使用教师可理解的中文业务描述。

### 3. 建立快速生成入口和长任务界面

- 新建课程后直接进入“快速生成”，右上角保留单向进入高级分步设计的入口。
- 快速模式只保留对话式输入和图片、语音、视频、丰富互动四个明确开关，不再显示课程标题或重复说明。
- 运行态左侧使用真实内容翻卡片，右侧只展示当前操作和最近有效结果，不重复列出动画已经表达的阶段。

### 4. 建立持久、可恢复的快速生成任务

- 快速设计完成后继续在同一全屏画布展示最终课堂生成，不跳转普通生成页面。
- 知识图谱数据在等待画布中转换为“基础—核心—应用—拓展”的学习逻辑分层，避免为了展示图谱而使用难读的气泡关系图；评价使用两层实体嵌套圆环，后方宽淡色环按实际占比分为教师评与 AI 评，前方细彩色环逐条编码规则颜色与权重，并在旁侧展示规则标题和可观察判据；六阶段使用时间带，页面制作和媒体资源各自使用专属构图。所有构图使用系统暖白、教师蓝、细边框与小圆角；主卡自身悬浮，左右侧卡缩小后退并独立运动，不得用主卡背后的垫片卡伪造层次；切换使用新旧卡交叠的连续透视翻页，不出现空白断帧。进度条只使用低对比度渐变缓流与轻微端点呼吸，侧卡标题必须截断，避免长标题破坏卡堆轮廓。
- 每张卡片设置最短可读时长，生成任务不因前端展示节奏暂停。
- 总预计时间包含课程设计和最终课堂页面生成；进入最终阶段后使用实际页面数和观测速度更新。
- 最终课堂与教师资源在生成完成时自动存档，不依赖发布按钮。

- 新增每门课程唯一的设计生成任务和迁移。
- API 支持创建、查询、失败后重试，避免重复生成。
- Worker 逐阶段写入课程的标准字段与追溯记录；云端后台运行，本机采用同接口的前台推进。
- 页面大纲保存后开放约 10 秒审阅窗口；进入详情时任务暂停，确认后原子保存当前编辑大纲并恢复，未进入则自动继续。
- 设计完成后排入现有最终课堂生成任务，复用现有课堂生成和资源生成链路。

### 5. 质量门与验证

- 检查知识图谱完整性、六阶段结构与总时长、主课脚本知识覆盖、评价权重和个性化路径覆盖。
- 自动生成结束前运行综合复核，保存可读的质量报告。
- 增加关键单元测试，运行定向测试、类型检查、lint 和生产构建。
