# ADR-0003：采用学习证据驱动的无感资源编排

## 状态

Accepted。取代 ADR-0002 中按学生层次选择“补基础/拓展分支”的决策方式；保留其“全部资源备课期生成”的决定。

## 背景

按前测总分划分基础、平均和优秀层次，会掩盖学生在具体知识点上的差异，也容易重复主课程已经包含的回顾内容。模块答错后再次讲授相同内容价值有限。弹窗播放额外资源还会暴露资源切换，破坏课程连续性。

## 决策

- 主课程完整覆盖本节课要求，不因个性化路径删减。
- 前测最多 5 题，结果保存为知识点级缺口与掌握证据，不产生学生层次标签。
- 先决知识资源只在相关前测知识点答错时，于正式主课前插入。
- 模块测验约 3 题；答错进入解析和教师统计，只有达到掌握阈值且时间充足时才插入新例题、应用或拓展。
- 所有额外资源必须声明相对主课的新增价值和潜在重叠页。
- 学生端在同一播放器区域切换课堂资源，完成后自动返回主课程。
- 教师端按资源展示逐项条件实际值，不再展示学生层次。

## 结果

### 正面

- 避免以总分标签代替具体学习证据。
- 避免重复讲授主课已经覆盖的内容。
- 学生不会感知弹窗式资源切换。
- 教师可以在备课期控制全部可能出现的内容，并在授课期解释每次选择。

### 负面

- 备课生成需要完整主课大纲作为去重上下文。
- 教师需要审核每份资源的新增价值。
- 多个细粒度缺口仍受总时长预算限制，不保证全部播放。

### 中性

- 历史层次字段仅作为旧快照兼容类型保留，不参与新决策或界面展示。

## 备选方案

- 继续三层分流：无法表达具体知识缺口，且容易产生标签化体验。
- 错题后自动重讲：重复性强，会挤占新知识学习时间。
- 运行时生成：延迟与失败风险会破坏课堂连续性。
- 弹窗播放预生成资源：技术简单，但学生明显感知路径切换。
