# ADR 0015：白板按课堂页面隔离并在整课内保留

## 状态

Accepted — 2026-08-14。

## 背景

课堂白板数据保存在 `Stage.whiteboard[]`，但运行时动作写入最后一个白板，画布和工具栏读取第一个白板。页面切换没有明确的状态边界，导致上一页板书覆盖在下一页的新讲解上。

## 决策

- 每个课堂页面使用稳定的白板标识 `whiteboard-scene:<sceneId>`。
- 白板动作只读写当前页面的白板；画布、元素数量、清空和历史恢复也指向同一页面白板。
- 首次在某页使用白板时按需创建空白板。进入下一页不删除上一页数据，而是展示下一页自己的白板；返回上一页时恢复其原有板书。
- 旧课堂中没有页面作用域标识的白板作为历史数据保留，但不自动叠加到当前页面。

## 取舍

相比整课共用一张无限白板，该方案不要求生成代理持续计算旧内容边界，也不会因坐标冲突遮挡后续讲解。相比翻页即清空，它保留了回看和复盘能力。代价是每个使用白板的页面会增加一个轻量白板对象。

## 失败处理

页面白板不存在时显示空白状态并按需创建；创建或写入失败时不复用其他页面白板，避免以旧内容掩盖错误。
