# ADR 0012：采用严格先修边界的个性化学习闭环

## 状态

Accepted — 2026-08-12。取代 ADR-0003 中“有实质性主课就必须生成前测”的隐含假设；保留知识点级证据、预生成资源和同一播放器无感插入。

## 背景

“自然语言处理”测试课程把中文分词、词性标注、文本分类和规则方法列为本课新授内容，却又把词语边界、词性、一般分类和条件规则包装成课前先修题。系统此前强制实质性课程识别 1–4 个先修知识，只做词面去重，没有独立判断这些内容是否真的应在开课前掌握，导致模型为了满足数量要求虚构低价值前测。补缺资源还允许同时覆盖多个独立缺口，使只错一题的学生也可能被迫回顾全部内容。

## 决策

- 个性化顺序固定为：必要先修分析 → 可选前测 → 按缺口补学 → 完整主课 → 唯一主课达标测 → 按逐知识点成绩与剩余时间选择可选拓展。
- 前测不是课程导入、预习、本课摸底或简化版课后测。它只能测量“学生按年级与已知学情理应在课前掌握，且缺失会直接阻断某个本课新授目标”的知识或技能。
- 生成器必须逐项记录主课知识的先修决策：需要诊断、在主课内教学，或该目标本身不需要额外先修。整门课程仍必须至少保留 1 项真实课程入口能力，推荐 2-4 项、最多 5 项；每项严格对应一道前测和一份独立补学资源。不得生成零题，也不得为了满足数量生成常识题、过低年级题、术语记忆题或本课新授内容的同义改写。
- 先修知识必须声明课前掌握依据、对主课的必要性和可观察诊断边界。所有主课知识、场景、学习目标、学生画像和年级同时进入判断上下文。
- 生成后的方案同时经过确定性结构门禁和独立 AI 语义审校。语义审校专门检查“是否应已掌握、是否真正必要、是否与本课新授重叠、题目是否有诊断价值和年级适切性”；不通过时由生成 Agent 带着具体问题重做完整方案。
- 每份先修补学资源只对应一个先修知识缺口，并绑定测试该缺口的题目。资源采用“定位误解 → 短讲解/具体例子 → 一道衔接检查”的微课结构，只为答错该知识的学生插入。
- 一旦前测确认存在先修缺口，对应补学就是进入主课前的必经队列，不受 AI 授知剩余时间或拓展资源名额限制。播放器必须在首次挂载前原子加载并按方案顺序组装全部命中资源，播放路径固定为“补学 A → 补学 B → … → 主课第一页”，不得先播放主课再异步跳回补学页。
- 独立生成的补学与拓展资源必须先生成系统配置语音资产后才能标记为 ready；学生播放器保留系统/教师配置的 TTS 提供方和音色，不得自行启用浏览器原生声音作为隐式降级。
- 主课是可独立进入的完整叙事单元。主课第一页必须问候并从本课导入开始，不得使用“上一页已经看到”等依赖补学或拓展页面的表述。补学和拓展使用嵌入式段落叙事，结束后平滑返回既定后继页面。
- 达标测仍是主课唯一计分测验。未达标只进入解析与教师证据，不追加循环测验；达标且有剩余时间时，才可从预生成库选择最多少量拓展资源。

## 结果

### 正面

- 前测与主课形成明确的课程边界，不再提前考查将要教学的概念。
- 没有真实先修依赖的课程不会生成伪诊断。
- 补学与具体错误知识一一对应，减少无关回顾和时间浪费。
- 学生进入课堂时不会短暂听到主课再经历多次刷新；多个补学或拓展资源形成单一连续播放队列。
- 补学、主课和拓展使用一致的配置音色，同时主课不再依赖只有部分学生会看到的个性化页面。
- 快速生成与详细生成共用同一生成及审校服务，避免提示词和质量标准漂移。

### 负面

- 个性化方案需要额外一次语义审校模型调用；当审校不通过时还需要一次修订调用。
- 旧课程不会自动获得新的先修分析证据，需要重新生成个性化方案。

### 中性

- 历史方案中的多知识点补缺资源仍可读取，但新生成和重新确认时必须通过新的单缺口门禁。

## 备选方案

- 只加强提示词：无法阻止模型以同义改写绕过“本课新授”词面检查。
- 只做确定性关键词去重：不能可靠判断学科语义、年级适切性和“必要而非仅有帮助”。
- 固定生成通用能力前测：会把分类、语法、逻辑等常识错误地泛化为所有课程的先修要求。
